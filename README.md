# Clinique Achifaa Oujda — Site Web

Site web officiel bilingue (Français / Arabe) pour la **Clinique Achifaa Oujda**, clinique privée multidisciplinaire dans la région de l'Oriental, Maroc.

## ✨ Fonctionnalités

- **Hero cinématique** avec image de la clinique, effets parallax, particules, marquee animé
- **17 spécialités médicales** filtrables par catégorie avec images dédiées
- **Section À propos** avec piliers (Mission · Valeurs · Engagement · Innovation)
- **Galerie** des installations (Scanner Siemens, bloc opératoire, soins intensifs)
- **Formulaire de prise de rendez-vous** en ligne
- **Bilingue** Français / Arabe avec direction RTL automatique
- **Responsive** desktop, tablette, mobile
- **Boutons flottants** Urgences 24/7 et WhatsApp

## 🎨 Identité visuelle

- Bleu primaire : `#2F80B7`
- Bleu foncé : `#1F5D8C`
- Vert santé : `#3BAA3F`
- Blanc + gris clair pour fonds lumineux

## 🚀 Démarrage local

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000

## 📁 Structure

- `index.html` — page complète (HTML + CSS + JS vanilla)
- `images/` — photos de la clinique + visuels des spécialités
